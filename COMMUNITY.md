## 🤝 Community Interaction Guide

### Getting Started

1. **Read README.md** - Understand what Block Game is
2. **Play the game** - Get familiar with it
3. **Read GUIDE.md** - Learn gameplay in detail
4. **Join discussions** - Connect with community

### Reporting Issues

1. **Check existing issues** - Avoid duplicates
2. **Read CONTRIBUTING.md** - Follow guidelines
3. **Create new issue** - Provide details
4. **Be respectful** - Follow CODE_OF_CONDUCT.md

### Contributing Code

1. **Fork repository** - Create your copy
2. **Read CONTRIBUTING.md** - Learn standards
3. **Create branch** - Use descriptive names
4. **Write code** - Follow guidelines
5. **Test thoroughly** - Check everything works
6. **Submit PR** - Wait for review
7. **Respond to feedback** - Make requested changes

### Reporting Security Issues

1. **Don't create public issue** - Keep it private
2. **Email: manjasanand08@gmail.com** - Send report
3. **Include details** - Be specific
4. **Wait for response** - 24 hour acknowledgment
5. **Discuss fix** - Work with maintainers
